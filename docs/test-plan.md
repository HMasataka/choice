# テスト計画書

WebRTC SFU のテスト計画書。本ドキュメントでは、テストの種類、テストケース、テスト環境、受け入れ基準を定義する。

## 1. テスト戦略

### 1.1 テストピラミッド

```text
┌─────────────────┐
│    E2Eテスト    │  ← ブラウザ自動化（少数）
├─────────────────┤
│  統合テスト     │  ← API/WebSocket/WebRTC（中程度）
├─────────────────┤
│  ユニットテスト │  ← 関数/メソッド単位（多数）
└─────────────────┘
```

### 1.2 テストカバレッジ目標

| 種類           | カバレッジ目標   | 備考                 |
| -------------- | ---------------- | -------------------- |
| ユニットテスト | 80%以上          | ビジネスロジック中心 |
| 統合テスト     | 主要パス100%     | API/シグナリング     |
| E2Eテスト      | クリティカルパス | 入退室、配信/受信    |

## 4. E2Eテスト

- **ブラウザ**: Chrome, Firefox, Safari (最新版)
- **自動化ツール**: Playwright または Puppeteer
